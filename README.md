# SECOND-HAND-COLLEGE-ITEM-EXCHANGE-SYSTEM

## Problem Statement / Objective
A platform for students to buy, sell, exchange, or donate second-hand college items (books, calculators, lab equipment, stationery, bags).

## Team Members
- Paridhi Sachan  
- Rohan Chaudhary  
- Kanav Arora  

## Technologies / Tools Used
- C/C++  
- Data Structures & Algorithms (Linked Lists, Queues, Stacks, Searching, Sorting)  
- File I/O for storage  
- GUI (Desktop-based)  

## Setup / Installation
1. Clone or download the repository.  
2. Compile the source code using a C++ compiler.  
3. Run the executable to launch the GUI application.  

## Major Features / Modules
- User authentication (sign up / login)  
- Item posting and browsing  
- Search and sort utilities  
- Exchange and donation requests  
- File-based storage  

## Current Project Status
- Backend, frontend, and file storage are still in progress.
